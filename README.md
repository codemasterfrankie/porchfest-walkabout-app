# Welcome to the Porchfest Walkabout App

This app's job is to augment your [Porchfest](https://www.porchfest.org/) experience [(read more about Porchfest here)](https://en.wikipedia.org/wiki/Porchfest). The app isn't deployed as of November 2026. Here's how the final version of this app will work: after selecting your town's Porchfest, during the hours of the festival, this app will tell you what band you are nearby. Rather than scrambling to find the schedule online and cross-referencing the porch address, festival-goers now have the freedom to wander where the music takes them and quickly find out what performers they're enjoying. After the festival window ends, the app will display a list of all bands visited.

This app was created by Jaden Rieck as a senior year project at Ithaca College under the mentorship of Computer Science professor Doug Turnbull. Jaden's role in this project is as an HCI designer and front- and back-end developer. They decided the implementation tools, languages, and frameworks and was the sole contributor to the current version of the app.

The development of is app was part mobile development exploration, part local-music passion project, part agentic experimentation. LLMs were utilized in researching and selecting the right framework and architecture for this app.

## Tools

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app). Expo was selected because of the simplicity in deploying both to Apple and Android OS.

## Get started


1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

In the output, you'll find options to open the app in a

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), a limited sandbox for trying out app development with Expo

You can start developing by editing the files inside the **app** directory. This project uses [file-based routing](https://docs.expo.dev/router/introduction).
